# Security Policy

Runvora is in early development and has no released versions with a formal support policy.

## Reporting a vulnerability

Do not report security vulnerabilities through public issues, pull requests, or discussions.

Use GitHub private vulnerability reporting on the affected repository (the **Security** tab, then **Report a vulnerability**), if it is available. If it is not available, open a public issue asking maintainers for a private contact method, without including any vulnerability details.

Please include the affected component, reproduction steps, and potential impact. Never include real credentials or sensitive data.
