# Contributing to Runvora

Runvora is in early development, and processes may change.

## Guidelines

- Write code, documentation, commit messages, issues, and pull requests in English.
- Search existing issues and pull requests before starting work.
- Open an issue to discuss significant changes before implementing them.
- Prefer one focused change per branch and pull request.
- Run the relevant checks for the repository and report the results in your pull request.
- Update documentation together with behavior changes.
- Never commit credentials, tokens, private keys, or sensitive information.

AI agents must also follow the [organization-wide agent protocol](AGENTS.md).

By participating, you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md). Report security issues as described in [SECURITY.md](SECURITY.md).
