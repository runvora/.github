# Runvora

**Automation beyond APIs.**

Runvora is a platform being built to make applications accessible through reusable actions, even when they don't provide an official API.

Our goal is to enable developers, users, and AI agents to discover, create, share, and execute automations while keeping execution, credentials, and permissions under the user's control.

## Principles

- **Local execution** — run automations in environments you control.
- **Reusable automation** — expose application capabilities as standardized, structured actions.
- **Community collaboration** — build, share, and reuse automation implementations.
- **AI accessibility** — make capabilities available to AI agents through structured interfaces.
- **User-controlled permissions** — decide what applications and AI agents are allowed to execute.

## Project status

Runvora is in early development. The architecture, developer tooling, and initial platform components are being designed. More information will be available as the project evolves.
