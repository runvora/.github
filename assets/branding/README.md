# Branding

This directory is reserved for future Runvora brand assets. No approved brand assets exist yet, and no temporary graphics are included.

## Proposed direction

- A minimalist geometric **R** monogram.
- A play symbol integrated into the letter R.
- A distinctive, original design that does not copy existing commercial logos.
- Suitable for application icons, favicons, GitHub avatars, and documentation.
- Support for both light and dark backgrounds.
- SVG as the preferred source format.

Assets added here should be approved by the maintainers before use.
